Project Overview

The project explores whether unsupervised visual groupings can reveal useful structure in plant image collections without training a supervised classifier.

Problem

Discover visual plant groups

Given a collection of plant images, the pipeline clusters images by visual similarity and evaluates how those groups compare with available taxonomy labels.

Approach

Compare feature representations

It tests flattened raw pixels, handcrafted color histogram plus HOG descriptors, and CNN embeddings from a pretrained ResNet-style backbone.

Deliverable

Reproducible experiment bundle

Each run saves metrics, tables, figures, limitation notes, and a config snapshot for consistent reporting.

Pipeline

The repo separates data loading, feature extraction, clustering, evaluation, visualization, and experiment orchestration into focused Python modules.

1

Load Images

Use iNaturalist 2021 Plantae images or local ImageFolder-style data.

2

Extract Features

Build raw pixel, handcrafted, or CNN embedding matrices.

3

Preprocess

Standardize features and apply PCA to raw pixels when enabled.

4

Cluster

Run K-Means with k-means++ initialization across the configured k range.

5

Evaluate

Report silhouette, ARI, NMI, cluster balance, and per-cluster diagnostics.

Methods

The implementation is designed for comparison rather than a single model choice, so the same clustering and evaluation flow can be applied to each feature space.

Raw Pixels

Images are resized to 64 by 64 RGB, normalized to [0, 1], flattened, standardized, and optionally reduced with PCA.

Handcrafted Features

Color histograms capture coarse RGB distribution while HOG captures local shape and texture cues.

CNN Embeddings

Pretrained CNN features use 224 by 224 inputs and remove the classifier head to produce image embeddings for clustering.

K Selection

The default search tries k from 2 through 10 and selects the best value by mean silhouette score.

Data Sources

The default configuration uses iNaturalist 2021, filtered to Plantae. A local folder mode is also available for smaller custom datasets.

iNaturalist 2021

Uses torchvision.datasets.INaturalist, filters categories whose kingdom is Plantae, and subsamples with the configured random seed.

Local Image Folders

Supports folder labels such as data/raw/trees/, data/raw/bushes/, and data/raw/flowers/.

Diagnostic Labels

Labels are not used to train the clusters. They are only used after clustering for ARI and NMI diagnostics.

Run the Project

The site is static, but the project itself is a Python experiment package with pip and conda setup options.

Setup

pip install -r requirements.txt

# or
conda env create -f environment.yml
conda activate plant_clustering

Experiments

python scripts/run_experiments.py
python scripts/run_experiments.py --quick
python scripts/run_experiments.py --no-ablations

python scripts/generate_figures.py results/experiments/run_YYYYMMDD_HHMMSS
python -m pytest tests/ -v

Repository Map

The codebase is intentionally modular so experiment settings, feature code, metrics, figures, and report materials stay easy to inspect.

The graduate report template is in reports/CS572_Grad_Final_Report.md. Contribution notes and citations live in CONTRIBUTION.md and CITATION.md.

  • config.pyDataset source, image sizes, k range, PCA, seed, and feature settings.
  • src/data_loader.pyiNaturalist and local folder loading utilities.
  • src/features.pyRaw pixel, handcrafted, and CNN embedding extraction.
  • src/clustering.pyK-Means, silhouette tuning, standardization, and PCA helpers.
  • src/evaluation.pyARI, NMI, cluster statistics, silhouette breakdown, and limitation notes.
  • src/visualization.pyFigure generation for silhouette curves, feature comparisons, and cluster sizes.
  • scripts/Runnable experiment and figure regeneration entry points.
  • tests/Pytest coverage for clustering and evaluation behavior.

Reproducibility

Runs are designed to leave an audit trail: the same seed, config snapshot, scripts, and saved result artifacts support consistent reporting.

Report Tables
